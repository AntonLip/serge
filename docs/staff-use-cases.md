# Use case: сотрудники и общие функции

Клиентские UC — в `client-use-cases.md` (UC-C01…UC-C08). Диаграммы — в `diagrams.md`.

Общие правила: серверные проверки ролей; изменяющие операции — POST + antiforgery; деньги в RUB (российских рублях); время UTC / Europe/Minsk.

---

## UC-A01. Войти в систему (сотрудник)

| Поле | Описание |
|---|---|
| **Актёр** | Любая staff-роль |
| **Предусловия** | Учётная запись создана и не заблокирована |
| **Основной поток** | Ввод email/пароля → проверка → рабочая панель `/` |
| **Альтернативы** | Неверные данные; блокировка; роль Client → редирект в `/Portal` |
| **Интерфейс** | `/Account/Login` |

## UC-A02. Выйти из системы

| Поле | Описание |
|---|---|
| **Актёр** | Авторизованный пользователь |
| **Основной поток** | POST Logout → сессия завершена → страница входа |
| **Интерфейс** | `POST /Account/Logout` |

## UC-A03. Просмотреть рабочую панель

| Поле | Описание |
|---|---|
| **Актёр** | Staff |
| **Основной поток** | Система показывает счётчики: новые заявки, просроченные, активные наряды, доступная техника, ТО ≤14 дней, договоры ≤30 дней, последние 6 заявок |
| **Интерфейс** | `/` |

## Наряды

## UC-W01. Просмотреть наряды

| Поле | Описание |
|---|---|
| **Актёр** | Staff (бригадир — преимущественно свои) |
| **Интерфейс** | `/WorkOrders`, `/WorkOrders/Details/{id}`, `/WorkOrders/Print/{id}` |

## UC-W02. Создать наряд

| Поле | Описание |
|---|---|
| **Актёр** | Админ, Диспетчер |
| **Предусловия** | Заявка Согласована, наряда ещё нет |
| **Основной поток** | Бригада, интервал, опционально несколько машин → наряд Плановый; заявка Назначена; техника Назначена |
| **Альтернативы** | Пересечение бригады/машины/водителя; машина без водителя / недоступна; конец ≤ начала |
| **Постусловия** | SignalR; один наряд на заявку |
| **Интерфейс** | `/WorkOrders/Create` |

## UC-W03. Начать работы по наряду

| Поле | Описание |
|---|---|
| **Актёр** | Бригадир (своей бригады), Админ |
| **Предусловия** | Наряд в статусе плановый/назначенный |
| **Основной поток** | Наряд В работе; заявка В работе |
| **Интерфейс** | `POST /WorkOrders/Start` |

## UC-W04. Сдать отчёт о выполнении

| Поле | Описание |
|---|---|
| **Актёр** | Бригадир (своей бригады), Админ |
| **Основной поток** | Факт объёма, трудозатраты, материалы, комментарий; до 5 фото JPG/PNG ≤5 МБ → наряд и заявка Выполнены; техника освобождается при отсутствии других активных назначений |
| **Альтернативы** | Неверный тип/размер фото → ошибки валидации |
| **Интерфейс** | `/WorkOrders/Complete` |

## UC-W05. Просмотреть фото отчёта

|---|---|
| **Актёр** | Staff с доступом к наряду |

| **Альтернативы** | Активный наряд → запрет |
