# Диаграммы CleanDistrict

Все рисунки для пояснительной записки ведутся в формате **diagrams.net / draw.io**:

**Файл:** [`clean-district-diagrams.drawio`](clean-district-diagrams.drawio)

Открывать в [diagrams.net](https://app.diagrams.net/), VS Code (расширение Draw.io Integration) или desktop Draw.io. Для ВКР: Файл → Экспорт как → PNG/SVG/PDF по страницам.

Генератор (пересборка при правках структуры): `_gen_drawio.py`.

Связанные тексты: `precedents.md`, `staff-scenarios.md`, `staff-use-cases.md`, `client-scenarios.md`, `client-use-cases.md`, `domain-rules.md`.

## Как вставить в пояснительную записку

1. Открыть `clean-district-diagrams.drawio`.
2. Выбрать нужную страницу внизу редактора.
3. При необходимости подправить расположение связей вручную.
4. Экспортировать страницу в PNG (300 dpi) или SVG.
5. В тексте: «Диаграмма прецедентов представлена на рисунке N» — сослаться на экспорт страницы 1 и т.д.
