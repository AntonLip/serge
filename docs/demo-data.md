## Запуск

### Docker Compose

Требуются Docker и Docker Compose:

```bash
docker compose up --build -d
```

Приложение доступно по адресу `http://localhost:5080`. Контейнер запускается после готовности PostgreSQL, автоматически применяет миграции и заполняет пустую базу демонстрационными данными. База, загруженные файлы и ключи Data Protection хранятся в именованных томах `cleandistrict_pgdata`, `cleandistrict_uploads` и `cleandistrict_dataprotection`.

Остановка без удаления данных:

```bash
docker compose down
```

### Локальный запуск

Требуются .NET SDK 10 и Docker с Docker Compose:

```bash
docker compose up -d postgres
dotnet restore
dotnet tool restore
dotnet ef database update --project src/CleanDistrict.Infrastructure/CleanDistrict.Infrastructure.csproj --startup-project src/CleanDistrict.Web/CleanDistrict.Web.csproj
dotnet run --project src/CleanDistrict.Web/CleanDistrict.Web.csproj
```

При Development-запуске приложение само применяет миграции и однократно заполняет пустую базу демонстрационными данными. Адрес HTTP по умолчанию указан в выводе `dotnet run`; для отдельного порта можно добавить `--urls http://localhost:5080`.
